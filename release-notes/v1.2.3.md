# v1.2.3 — Windows 安全修订版

本版本基于上游 Windows Agent 1.2.3，包含 Windows 专用的安全与资源管理修复。Agent 上报版本继续保持 **1.2.3**，与 Linux Agent 版本对齐，既有 Facts/Metrics 字段保持兼容。

**本构建不同于上游原始 v1.2.3 二进制。** 请以 `BaeKey/monitor-agent-win` 本次发布的附件及 SHA-256 校验和为准，不能将相同版本字符串视为相同构建。

## 安全与可靠性修复

- 配置写入前设置严格权限，使用逐组件验证的目录句柄执行文件操作，防止重解析点、硬链接和路径替换攻击。
- 安装与升级串行化、原子替换，支持完整服务配置快照、多实例恢复和持久化中断恢复记录。
- 对 TCP 探测、DNS、WebSocket 控制消息、日志和指标采集增加并发、速率、队列及大小限制。
- token 自有缓冲尽量清零，认证仅放在敏感 Bearer header；保留 TLS 校验。
- 修复重连后的指标基线、load 采样，以及自定义服务名实例的启动配置读取。

## 升级前须知

1. **私网 TCP 探测需要本机显式授权。** 默认仅允许公网目标，可用 `--probe-allow "192.168.1.10@443,10.0.0.0/24@443"` 或配置项 `MONITOR_PROBE_ALLOW` 追加授权；此限制不影响连接管理员配置的 hub。
2. 不可信所有者、危险权限或重解析路径的配置目录会被拒绝，请管理员检查后迁移。运行时配置必须只允许可信账户读取。
3. 安装进程被强杀或断电后，下次管理员执行 `install` 时会尝试恢复。不要手工删除 `.install-recovery.json` 及其引用的备份。
4. 服务名 `agent`（含大小写变体）及 Windows 设备保留名被拒绝，避免与默认配置、日志冲突。
